# 十组固定协议：全新采集

使用既有十组测试公钥，fixture seeds 101,103,105,107,109,111,113,115,117,119。
每组全新采集全部 11×1184 个系数；旧 SPRT 成功试跑不计入。无 vote3。
六核单组计时，组间串行；不同时在相同 CPU 上测量两组。

双侧符号 Bernoulli 混合 SPRT：备择概率 .51/.525/.55/.6/.7/.8/.9，
方向阈值 2/α，α=.001；N 至少 32，每批 16，上限 1000。边界在单次检验中固定，
不重启检验直到成功。到上限输出最佳三值猜测，保留完整证据和置信度。
这是混合 SPRT / e-process 顺序检验，不是两个完全指定分布间的经典 Wald SPRT；
其条件符号假设不自动保证物理桶判错率，候选分数也不是后验概率。

固定到 CPU 1/2/4/5/7/6；RDTSCP+LFENCE；C 内相邻随机目标/参考对，交错两轴。
每 worker 预热 400 次，3×1000 对校准，正间隔、最大不超过最小两倍；最多三次尝试。
每 128 个系数重新校准，每系数检查 32 对局部参考。参考不稳不删除最终猜测，
它降低候选的优先保留等级。原始 CSV 保存全部实际采样差分、N 和校准状态。

依据三值公开桶签名，把两轴混合 log evidence 相加选最佳候选，保留原可靠判决；
最佳与次优候选的分数差作为排序分数。原未决或参考拒绝的位置优先进入纠错窗口，
同组内置信度越低越先修改。支持集逐步扩展，高置信度不永久冻结。

公钥纠错固定窗口/方程/权重/秒数：
60/80/1/25，120/128/1/25，180/140/2/25，236/160/2/25，360/200/2/45，640/256/2/45。
三列并行、每列单核、BLASter beta=40，稀疏修正嵌入格。不得按真值调排序或预算。
独立全部公钥方程检查后才审计历史同公钥真值；完整 11 列成功则额外验证随机 KEM、
AES-GCM 和负例。捕获阶段不输出秘密或精确桶。求解不借用历史恢复列。

每组统计实际物理时间、采集进程时间、全部解封装次数、校准成本、实际 N 分布、
强制猜测数、猜测错误数（事后）、格纠错时间、接受列数和完整密钥验证状态。
采集失败保留日志并计为失败，不重新采到成功。尚未完成与失败分开报告。
本批次不根据已完成组的真值诊断调整后续组参数。

执行 `suite.py --preflight` 只核对依赖和输入；`suite.py` 创建新 runs 目录并顺序完成十组。
运行中每 30 秒保存心跳；每组完成后更新 REPORT.md 和 summary.json；全部结束自动汇总。
输出目录若存在即拒绝启动，避免重复采集或覆盖。源码、采集器和固定输入均保存 SHA256。
上一次第 1 组原始差分用于后处理一致性检查，结果保存为 smoke，不计入十组统计。
